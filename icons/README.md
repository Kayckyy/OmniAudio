# Ícones do Omni Audio Processor

## Arquivos de Ícone

- `app_icon.ico` - Formato ICO para Windows (contém múltiplos tamanhos)
- `app_icon.png` - Formato PNG para compatibilidade geral
- `app_icon.svg` - Formato SVG vetorial (para edição)

## Como Personalizar

1. Substitua os arquivos existentes pelos seus próprios ícones mantendo os mesmos nomes
2. Formatos recomendados:
   - **ICO**: Melhor para Windows, suporta múltiplos tamanhos em um arquivo
   - **PNG**: Funciona em todas as plataformas, qualidade boa
   - **SVG**: Vetorial, ideal para edição e redimensionamento

## Tamanhos Recomendados

- 16x16 - Barra de tarefas
- 32x32 - Ícones pequenos
- 48x48 - Ícones médios
- 64x64 - Ícones grandes
- 128x128 - Alta resolução
- 256x256 - Máxima qualidade

## Notas

- O programa tentará carregar o arquivo `.ico` primeiro, depois o `.png` como fallback
- Certifique-se de que os ícones tenham fundo transparente para melhor aparência
- O código já está configurado para carregar automaticamente os ícones na inicialização
